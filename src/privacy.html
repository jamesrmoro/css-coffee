Política de Privacidade - CSS Coffee

Última atualização: 25 de novembro de 2026

O CSS Coffee é um jogo educativo gratuito para aprender CSS Flexbox. Esta política explica quais dados o aplicativo usa.

Dados que coletamos

Nenhum. O CSS Coffee não pede cadastro, não coleta dados pessoais, não usa anúncios, não usa ferramentas de análise (analytics) e não compartilha informações com terceiros.

Dados salvos no seu aparelho

Para lembrar seu progresso, o jogo salva apenas no armazenamento local do seu aparelho (localStorage): o nível atual, os níveis concluídos, as respostas digitadas e o idioma escolhido. Esses dados nunca são enviados para nenhum servidor. Você pode apagá-los a qualquer momento em “Níveis → Zerar progresso” ou limpando os dados do aplicativo.

Funcionamento offline

O jogo usa um service worker para guardar seus próprios arquivos (páginas, imagens, fontes) no aparelho e funcionar sem internet. Nenhum dado pessoal é armazenado nesse cache.

Links externos

A tela “Sobre” tem um link para o canal do YouTube @sprintcodes. Ao abri-lo, vale a política de privacidade do YouTube.

Crianças

O aplicativo não coleta dados de nenhum usuário, inclusive de crianças.

Contato

Dúvidas sobre esta política: contato@sprintcodes.com.br

Privacy Policy - CSS Coffee

Last updated: November 25, 2026

CSS Coffee is a free educational game for learning CSS Flexbox. This policy explains what data the app uses.

Data we collect

None. CSS Coffee does not require an account, does not collect personal data, shows no ads, uses no analytics and shares no information with third parties.

Data stored on your device

To remember your progress, the game stores only in your device's local storage (localStorage): your current level, solved levels, typed answers and chosen language. This data is never sent to any server. You can erase it at any time via “Levels → Reset progress” or by clearing the app's data.

Offline use

The game uses a service worker to keep its own files (pages, images, fonts) on your device so it works without internet. No personal data is stored in this cache.

External links

The “About” screen links to the @sprintcodes YouTube channel. YouTube's privacy policy applies when you open it.

Children

The app does not collect data from any user, including children.

Contact

Questions about this policy: contato@sprintcodes.com.br
